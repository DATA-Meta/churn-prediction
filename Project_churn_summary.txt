# Netflix Churn Prediction - Project Summary (v2)

Dataset: 25,000 synthetic streaming customers (Mar 2024 - Mar 2025), simulated churn label (45% churn)
Best model: XGBoost (class-weighted), threshold tuned to 0.35
Test set: ROC-AUC 0.686 | PR-AUC 0.634 | F1 0.647 | Recall 0.867 | Precision 0.516
Baseline (majority class): ROC-AUC 0.500 | F1 0.000

Key drivers (permutation importance):
1. Subscription plan - Basic 62% churn, Standard 45%, Premium 29%
2. Watch time - light viewers (0-200h) 55% churn, heavy viewers (800h+) 28%
3. Favourite genre - Sci-Fi/Drama fans churn least (~37-39%)
Age and country have little effect.

Recommendations:
1. Upgrade offers for Basic-plan customers
2. Re-engage light viewers with personalised recommendations
3. Review content for higher-churn genres

v1 lesson: the original label (500+ days since last login) depended only on login date;
features had no signal (ROC-AUC 0.50) and the model predicted everyone as churned.
